# Function Composition

## 🧠 Big Idea

Function composition means using the output of one function as the input of another.

Instead of applying two rules separately, composition chains them together. The order matters because doing $g$ first and then $f$ can give a different result from doing $f$ first and then $g$.

## 📐 Equation Meaning

$$
(f\circ g)(x)=f(g(x))
$$

This means first apply $g$ to the input $x$, then apply $f$ to the result. The expression $g(x)$ becomes the input for the outer function $f$.

## 👀 Intuition

Think of two machines connected in a line. The first machine changes the original input. Its output drops directly into the second machine.

If you switch the machines, the final result may change. A “double and then add $1$” machine is not the same as an “add $1$ and then double” machine.

## 🔍 Simple Example

Let $f(u)=u^2$ and $g(x)=x+3$. Then

$$
(f\circ g)(x)=f(g(x))=f(x+3)=(x+3)^2
$$

This says composition first adds $3$ to $x$, then squares the result.

At $x=2$,

$$
(f\circ g)(2)=(2+3)^2=25
$$

This means the composed function sends input $2$ to output $25$.

## ⚠️ Careful

$f\circ g$ is read right to left: $g$ happens first, then $f$.

## 🔗 Connection

Order really matters. With $f(u)=u^2$ and $g(x)=x+3$, the reverse composition gives $(g\circ f)(x)=g(x^2)=x^2+3$, which is different from $(x+3)^2$. Composition is also the foundation of the **chain rule**, where you differentiate one function nested inside another.

## 🔑 Remember

Composition feeds one function’s output into another function.
