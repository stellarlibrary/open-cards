# Average Value of a Function

## 🧠 Big Idea

The average value of a function is the constant height that would give the same total accumulation over an interval.

For a list of numbers, an average adds the values and divides by how many there are. For a function with infinitely many input values, integration adds continuously, and the interval length plays the role of “how many.”

## 📐 Equation Meaning

$$
f_{\text{avg}}=\frac{1}{b-a}\int_a^b f(x)\,dx
$$

This means the average value of $f$ on $[a,b]$ equals its total net accumulation divided by the interval length. The integral adds the function’s values continuously, and $b-a$ is the width of the interval.

If $f$ is nonnegative, this average is the height of a rectangle with the same area as the region under the curve.

## 👀 Intuition

Imagine smoothing a bumpy graph into a flat horizontal line without changing the total area over the interval. The height of that flat line is the average value.

For temperature, it is like replacing a changing temperature over time with one steady temperature that has the same overall effect.

## 🔍 Simple Example

Find the average value of $f(x)=x^2$ on $[0,3]$.

$$
f_{\text{avg}}=\frac{1}{3-0}\int_0^3 x^2\,dx=\frac{1}{3}\cdot 9=3
$$

This means the constant function $3$ has the same total area on $[0,3]$ as $x^2$ does.

## 🔗 Connection

Average value uses FTC Part 2 to compute the integral, but its meaning is about replacing changing height with one equivalent constant height.

## 🔑 Remember

Average value is total accumulation divided by interval length.
