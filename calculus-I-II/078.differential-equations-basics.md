# What Is a Differential Equation?

## 🧠 Big Idea

A differential equation is an equation whose unknown is a function, and the equation includes one or more derivatives of that function.

Instead of asking for a number, it asks for a whole function whose rate of change behaves in a specified way. This makes differential equations natural for modeling motion, population, temperature, mixing, and many other changing quantities.

## 📐 Equation Meaning

$$
\frac{dy}{dx}=F(x,y)
$$

This means the derivative of $y$ with respect to $x$ is determined by a rule involving $x$, $y$, or both. The symbol $y$ represents the unknown function, $\frac{dy}{dx}$ represents its rate of change, and $F(x,y)$ describes how that rate is controlled.

A solution is not just a value of $y$. A solution is a function $y(x)$ that makes the equation true for all relevant $x$-values.

## 👀 Intuition

Think of a differential equation as a set of instructions for how a curve should move. At each point, the equation tells the curve what slope it should have.

Solving the equation means finding a curve that follows those slope instructions everywhere.

## 🔍 Simple Example

$$
\frac{dy}{dx}=2x
$$

This equation says the slope of the unknown function at each input $x$ should be $2x$.

One family of solutions is

$$
y=x^2+C
$$

This works because the derivative of $x^2+C$ is $2x$. The constant $C$ gives different vertical shifts, and each shifted curve has the same derivative.

## 🔑 Remember

A differential equation describes a function by describing how it changes.
