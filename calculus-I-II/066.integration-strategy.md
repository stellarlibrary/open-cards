# Integration Strategy

## 🧠 Big Idea

Integration strategy means choosing a path when an antiderivative is not obvious. Unlike differentiation, integration has no single rule that always works. The main skill is recognizing the structure of the integrand before doing algebra.

A good strategy starts with the simplest questions: Can I simplify it? Can I split it? Is there an inside function with its derivative nearby? Does it look like a product, a trig identity, a rational function, or a radical pattern?

## 📐 Equation Meaning

$$
\int f(x)\,dx \quad \longrightarrow \quad \text{choose a method from the form of } f(x)
$$

This means the expression $f(x)$ gives clues about the method. The symbol $\int f(x)\,dx$ asks for an antiderivative, but the arrow reminds us that the way forward depends on the shape of the integrand, not just on memorizing formulas.

## 👀 Intuition

Think of integration like untangling a knot. Some knots loosen if you pull one strand; others need to be rotated, separated, or transformed first. Substitution changes variables, integration by parts separates a product, trig identities rewrite powers, and partial fractions break rational expressions into smaller pieces.

## 🔍 Simple Example

For

$$
\int x\cos(x^2)\,dx
$$

look for an inside function. Since $x^2$ is inside cosine and its derivative is $2x$, substitution is natural. Let $u=x^2$, so $du=2x\,dx$. Then

$$
\int x\cos(x^2)\,dx=\frac12\int \cos u\,du=\frac12\sin u+C
$$

This means the original integral is $\frac12\sin(x^2)+C$.

## 🔑 Remember

First read the integrand’s shape; then choose the tool that matches it.
