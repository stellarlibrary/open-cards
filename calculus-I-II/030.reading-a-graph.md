# Reading a Graph

## 🧠 Big Idea

A graph is a picture of a function’s input-output behavior.

For a function $y=f(x)$, horizontal position represents the input $x$, and vertical position represents the output $f(x)$. Reading a graph means translating points, heights, intercepts, and trends into statements about the function.

## 📐 Equation Meaning

$$
(a,b)\text{ is on the graph of }y=f(x) \quad \Longleftrightarrow \quad f(a)=b
$$

This means that if the graph passes through the point $(a,b)$, then input $a$ gives output $b$. The $x$-coordinate is the input, and the $y$-coordinate is the function value.

## 👀 Intuition

Think of the graph as a landscape. Moving left to right changes the input. Looking up or down shows the output.

If the graph rises as you move right, the function values are increasing. If it falls, the function values are decreasing. Where it crosses the $x$-axis, the output is $0$.

## 🔍 Simple Example

Suppose the graph of $y=f(x)$ passes through $(2,5)$ and crosses the $x$-axis at $x=-1$.

From the point $(2,5)$, we know

$$
f(2)=5
$$

This says the output is $5$ when the input is $2$.

From the $x$-axis crossing, we know

$$
f(-1)=0
$$

This says $-1$ is a zero of the function.

## ⚠️ Careful

Do not read the coordinates backward. The input comes from the horizontal axis; the output comes from the vertical axis.

## 🔑 Remember

A point on a graph is an input-output pair.
