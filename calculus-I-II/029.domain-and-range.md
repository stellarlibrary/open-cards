# Domain and Range

## 🧠 Big Idea

The domain and range describe where a function can start and where it can end.

The **domain** is the set of inputs that are allowed. The **range** is the set of outputs the function actually produces. Together, they tell you the function’s possible input-output world.

## 📐 Equation Meaning

$$
\text{domain}=\{x:\ f(x)\text{ is defined}\}, \qquad
\text{range}=\{f(x):x\text{ is in the domain}\}
$$

This means the domain contains every input $x$ that makes sense for the function, while the range contains the resulting output values $f(x)$ from those inputs.

## 👀 Intuition

Imagine a vending machine. The domain is the set of buttons that actually work. The range is the set of snacks the machine can give you.

Some inputs are blocked because they would break the rule. For example, square roots need nonnegative radicands, and fractions cannot have zero in the denominator.

## 🔍 Simple Example

Let

$$
f(x)=\sqrt{x-2}
$$

This function is defined only when the quantity under the square root is nonnegative.

So we need

$$
x-2\ge 0
$$

This inequality says the input must satisfy $x\ge 2$.

Therefore the domain is $[2,\infty)$. Since square roots are never negative, the range is $[0,\infty)$.

## ⚠️ Careful

The range is not always obvious from the formula. It depends on what outputs actually occur after using the allowed inputs.

## 🔑 Remember

Domain asks “what inputs work?”; range asks “what outputs happen?”
