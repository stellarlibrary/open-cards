# Intermediate Value Theorem

## 🧠 Big Idea

If a continuous function moves from one value to another, it must pass through every value in between. It cannot skip a level.

This theorem guarantees that solutions **exist**, even when we can't find them exactly. It's the foundation for many root-finding ideas.

## 📐 Equation Meaning

If $f$ is continuous on $[a,b]$ and $N$ is any value between $f(a)$ and $f(b)$, then there exists some $c$ in $(a,b)$ with

$$
f(c)=N
$$

This means: a continuous function takes on every height between its starting and ending heights. Somewhere in the interval, it hits the target value $N$.

## Why It Matters

The IVT is an **existence** tool. It doesn't tell you *where* the value is, only that it's guaranteed to be there. This justifies the bisection method and proves equations have solutions.

## 👀 Intuition

Picture hiking from an elevation of $100$ m to $500$ m along a continuous trail. At some point you must have stood at exactly $300$ m — there's no way to teleport past it.

## 🔍 Simple Example

Let $f(x)=x^3+x-1$, which is continuous. Then

$$
f(0)=-1, \qquad f(1)=1
$$

Since $0$ lies between $-1$ and $1$, the IVT guarantees a root $c$ in $(0,1)$ where $f(c)=0$.

## ⚠️ Careful

Continuity on the **whole** interval is required. If the function jumps, it can skip over $N$ entirely and the guarantee fails.

## 🔑 Remember

A continuous function can't skip values — it must pass through every level in between.
