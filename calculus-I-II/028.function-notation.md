# Function Notation

## 🧠 Big Idea

Function notation is a compact way to say, “give this rule an input, and it produces an output.”

When we write $f(x)$, the letter $f$ names the function and $x$ is the input being used. The whole expression $f(x)$ means the output of the function at that input. It is not multiplication between $f$ and $x$.

## 📐 Equation Meaning

$$
x \longmapsto f(x)
$$

This means the input $x$ is sent to the output $f(x)$. The arrow shows the action of the function: it takes a value from its domain and assigns exactly one output value.

## 👀 Intuition

Think of a function like a machine with a label on it. If the machine is named $f$, then $f(2)$ means “put $2$ into the $f$-machine and see what comes out.”

The notation also helps us talk about change. Comparing $f(2)$ and $f(5)$ means comparing the outputs from the same rule at two different inputs.

## 🔍 Simple Example

Let

$$
f(x)=x^2+3
$$

This means the function squares the input and then adds $3$.

To find $f(2)$, replace every $x$ with $2$:

$$
f(2)=2^2+3=7
$$

This says the output is $7$ when the input is $2$.

## ⚠️ Careful

The parentheses in $f(x)$ show the input. They do not mean multiplication, even though $2x$ does.

## 🔑 Remember

$f(x)$ means the output of function $f$ at input $x$.
