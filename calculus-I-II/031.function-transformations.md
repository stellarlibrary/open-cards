# Function Transformations

## 🧠 Big Idea

Function transformations change the graph of a familiar function without changing its basic identity.

Instead of graphing from scratch, you can recognize how shifts, stretches, compressions, and reflections move the original graph. The original function is often called the parent function.

## 📐 Equation Meaning

$$
g(x)=a\,f(b(x-h))+k
$$

This means $g$ is built by transforming $f$. The number $h$ shifts the graph horizontally, $k$ shifts it vertically, $a$ changes vertical size or reflects across the $x$-axis, and $b$ changes horizontal size or reflects across the $y$-axis.

## 👀 Intuition

Imagine the graph printed on a flexible sheet. You can slide the sheet left or right, move it up or down, stretch it taller, squeeze it wider, or flip it over an axis.

Outside changes, like $a$ and $k$, affect the outputs. Inside changes, like $b$ and $h$, affect the inputs, so they can feel reversed compared with what the formula visually suggests.

## 🔍 Simple Example

Start with the parent function $f(x)=x^2$. Now define

$$
g(x)=2(x-3)^2+1
$$

This means the parabola $y=x^2$ shifts right $3$ units, stretches vertically by a factor of $2$, and shifts up $1$ unit.

The vertex moves from $(0,0)$ to

$$
(3,1)
$$

This point is the new lowest point of the transformed parabola.

## ⚠️ Careful

A change inside the function affects horizontal behavior. For example, $f(x-3)$ shifts right, not left.

## 🔑 Remember

Outside changes affect outputs; inside changes affect inputs.
