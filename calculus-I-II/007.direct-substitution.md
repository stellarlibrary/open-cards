# Direct Substitution

## 🧠 Big Idea

For many friendly functions, finding a limit is as simple as plugging in the number. If the function behaves nicely at the point, the limit equals the function value.

This is the first thing to try with any limit. It works whenever the function is continuous at that point.

## 📐 Equation Meaning

$$
\lim_{x \to a} f(x)=f(a)
$$

This means: if $f$ is continuous at $a$, just substitute $x=a$ to get the answer. The limit and the function value are the same thing here.

This works for polynomials, and for rational, root, exponential, and trig functions wherever they are defined.

## 👀 Intuition

If a function has no holes, jumps, or blow-ups near a point, then where the function is heading is exactly where it actually is. There's no surprise, so plugging in works.

## 🔍 Simple Example

$$
\lim_{x \to 3} (2x^2-x+1)=2(3)^2-3+1=18-3+1=16
$$

A polynomial is continuous everywhere, so direct substitution gives the answer immediately.

## ⚠️ Careful

If substitution gives a determinate value, you're done. But if it gives an **indeterminate form** like $\frac{0}{0}$, substitution failed and you need another method, such as factoring or rationalizing.

## 🔗 Connection

Direct substitution working is exactly the definition of **continuity**: $f$ is continuous at $a$ precisely when $\lim_{x \to a} f(x)=f(a)$. So every continuous function lets you find limits by plugging in.

## 🔑 Remember

Always try plugging in first; it works whenever the function is continuous there.
