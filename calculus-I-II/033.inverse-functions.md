# Inverse Functions

## 🧠 Big Idea

An inverse function reverses what a function does.

If $f$ takes an input to an output, then $f^{-1}$ takes that output back to the original input. An inverse is possible as a function only when each output comes from exactly one input.

## 📐 Equation Meaning

$$
f^{-1}(y)=x \quad \Longleftrightarrow \quad f(x)=y
$$

This means $f$ sends $x$ to $y$, and the inverse function sends $y$ back to $x$. The two functions undo each other’s input-output assignments.

## 👀 Intuition

Picture a pair of reversible directions. If the original direction says “walk $3$ miles east,” the inverse says “walk $3$ miles west.”

On a graph, inverse functions swap inputs and outputs. That swap reflects the graph across the line $y=x$, because every point $(a,b)$ becomes $(b,a)$.

## 🔍 Simple Example

Let

$$
f(x)=2x+3
$$

This function doubles the input and then adds $3$.

To reverse it, subtract $3$ first and then divide by $2$:

$$
f^{-1}(x)=\frac{x-3}{2}
$$

This formula gives the input that must have produced the output $x$.

For example,

$$
f^{-1}(11)=\frac{11-3}{2}=4
$$

This says $11$ came from the original input $4$, since $f(4)=11$.

## ⚠️ Careful

$f^{-1}(x)$ means inverse function, not $\frac{1}{f(x)}$.

## 🔗 Connection

A function has an inverse only when it is **one-to-one** — each output comes from exactly one input. The **horizontal line test** checks this: if no horizontal line crosses the graph twice, the inverse exists. This is why $e^x$ (always increasing) has the inverse $\ln x$.

## 🔑 Remember

An inverse function runs the original input-output rule backward.
