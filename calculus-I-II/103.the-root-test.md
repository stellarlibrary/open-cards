# The Root Test

## 🧠 Big Idea

The root test measures the average exponential size of the terms in a series. It is most useful when terms contain something raised to the $n$th power.

Like the ratio test, it compares the tail to geometric behavior, but it does so by taking $n$th roots.

## 📐 Equation Meaning

$$
L=\lim_{n\to\infty}\sqrt[n]{|a_n|}
$$

This means $L$ measures the long-run base size hidden inside the $n$th term. If $L<1$, then $\sum a_n$ converges absolutely. If $L>1$ or $L=\infty$, then $\sum a_n$ diverges. If $L=1$, the test is inconclusive.

## 👀 Intuition

If the $n$th root of $|a_n|$ settles below $1$, then the terms act roughly like powers of a number smaller than $1$. Powers like that shrink quickly enough to produce a finite sum.

If the root settles above $1$, the terms do not even shrink to $0$.

## 🔍 Simple Example

For $\sum_{n=1}^{\infty}\left(\frac{2n+1}{3n}\right)^n$, let $a_n=\left(\frac{2n+1}{3n}\right)^n$.

$$
\sqrt[n]{|a_n|}=\frac{2n+1}{3n}
$$

This means the $n$th root removes the outer power. The limit is $\frac23$, which is less than $1$, so the series converges absolutely.

## ⚠️ Careful

The root test is inconclusive when $L=1$. That result does not mean the series is close to converging; it only means this test cannot decide.

## 🔑 Remember

The root test looks for the geometric base hidden inside the $n$th term.
